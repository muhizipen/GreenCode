# Contributing to GreenCode

Thank you for considering contributing to GreenCode!

## How to Contribute

1. **Fork the repository** - Create your own copy on GitHub
2. **Create a branch** - Use a descriptive name like `feature/your-feature`
3. **Make your changes** - Write code or improve documentation
4. **Commit your changes** - Use meaningful commit messages
5. **Push to your fork** - Upload your changes to GitHub
6. **Submit a pull request** - Propose your changes to the project

## Commit Message Guidelines

- Use present tense: "Add feature" not "Added feature"
- Be descriptive: "Fix typo in README" not "Fix stuff"
- Reference issues: "Closes #1" in the description

## Code Style

- Follow existing code conventions
- Write clear comments
- Test your changes before submitting

## Questions?

If you have any questions, please open an issue and we'll help you!
